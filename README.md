## 🚀 Projeto em Destaque

### 💈 Sistema de Agendamento para Barbearias
Aplicação **full stack** desenvolvida para resolver um problema real de organização de horários em barbearias.

**Principais características:**
- Front-end com **Next.js + Tailwind CSS**
- Back-end com **NestJS + PostgreSQL (Prisma)**
- Autenticação **JWT**
- Controle de horários (evita conflitos)
- Dashboard administrativo
- Regras de negócio reais

📌 Repositórios:
- Front-end: `barbearia-app`
- Back-end: `barbearia-api`
